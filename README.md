# Xenbase MCP

A small Xenbase-only MCP server for VS Code / GitHub Copilot.

## Tools

- `search_genes_tool`
- `check_gene_tool`
- `get_gene_page_tool`
- `get_human_orthologs_tool`
- `research_gene`

## Setup

From the project directory:

```bash
uv sync
uv run python scripts/update_xenbase_data.py
uv run mcp dev xenbase_mcp/server.py
```

The VS Code MCP configuration is in `.vscode/mcp.json`.

## Notes

The local export files are generated by the update script and are intentionally
not included in the source archive.
